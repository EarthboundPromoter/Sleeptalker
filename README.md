# Sleeptalker

A screen-reader accessibility mod for **Citizen Sleeper 2: Starward Vector** (BepInEx 5, Tolk, NVDA). Sibling project to [Citizen Speaker](https://github.com/EarthboundPromoter/Citizen-Speaker), the accessibility mod for the first Citizen Sleeper.

**Status: pre-alpha.** No playable build yet — groundwork and tooling stage.
